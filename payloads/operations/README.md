# Operations

Operations are not packages. They describe distro-specific setup, performance
policy, security baselines, and diagnostic utilities. Their commands and
preconditions live in JSON so the UI remains an adapter.

Linutil-inspired operations are normalized from the Ubuntu-relevant portions of
the [Linutil Store](https://linutil.christitus.com/userguide/store/),
[System Setup](https://linutil.christitus.com/userguide/tweaks/), and
[Features & Utilities](https://linutil.christitus.com/userguide/features/).
Gaming, Arch-only tooling, and whole desktop/window-manager replacement flows
are intentionally excluded from this initial payload.
